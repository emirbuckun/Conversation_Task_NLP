# CSE4078 NLP Term Project (Group 7 - 2024)

Welcome to the CSE4078 Natural Language Processing (NLP) Term Project repository.

## Project Overview

This project is designed to explore various aspects of Natural Language Processing (NLP), a subfield of artificial intelligence focused on the interaction between computers and human language. The project task for our group is conversation. We will focus on conversation datasets. Throughout the course, we will delve into different techniques, algorithms, and applications in NLP.

## Project Structure

The project is divided into four delivery stages, each building upon the previous one to incrementally develop NLP skills and understanding.

## Getting Started

To get started with the project, follow these steps:

**Clone the Repository:** Clone this repository to your local machine using the following command:

```
git clone https://github.com/yigit-ak/CSE4078S24_Grp7.git
```

**Navigate to Project Directory:** Enter the project directory:

```
cd CSE4078S24_Grp7
```

**Set Up Environment:** Set up your Python environment and install the required dependencies. You may use a virtual environment to manage dependencies.

**Start Working:** Start working on the project.
